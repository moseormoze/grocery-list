# Design: העתקת רשימה לשיתוף

סטטוס: העיצוב והמוקאפ המעודכנים אושרו ב-2026-11-16. אייקון ההעתקה מחליף את הצעת הכפתור הרחב, והתוכן הוא רשימה בלבד לפי [הבריף המעודכן](brief.md). הפירוק למשימות אושר; T1 ו-T2 מומשו; המיזוג עדיין ממתין לסקירת המשתמש.

## Screens Affected

בכותרת `/lists/[listId]`, ברשימות סופר בלבד, נוסף **אייקון העתקה ליד ״ערוך״**. זו פעולה ישירה בלחיצה אחת. אין תפריט נוסף, כפתור עם טקסט קבוע או שורת פעולות נוספת במסך צר.

- סדר RTL: חזרה, אייקון הסופר, שם הרשימה, העתקה, ״ערוך״.
- אייקון `Copy` בגודל 18 פיקסלים בתוך `.icon-btn` הקיים: שטח לחיצה 44×44, רדיוס 12, רקע שקוף וצבע `ink-70`. רק בריחוף או בלחיצה מופיע הרקע העדין הקיים.
- השם הנגיש ותווית הריחוף/פוקוס: ״העתק רשימה״. אין שיקוף לאייקון ההעתקה.
- הפעולה נשארת באותה שורה גם ב-375 פיקסלים. שם רשימה ארוך נחתך כפי שכבר נהוג, בלי לכווץ את יעדי הלחיצה או להסיר בקרות קיימות.
- מופיעה גם במצב ״ערוך״. תוכן של טופס שלא נשמר אינו מועתק.

## Components

- **Modified:** `ListDetailPage` — אייקון העתקה ומשוב מקומי בכותרת.
- **Reused:** `.icon-btn`, צבעים, גופן `Heebo` וגיבוייו הקיימים, ואייקוני Lucide.
- **New:** משוב מקומי קטן מתחת לאזור הפעולות, מעוגן לקצה שמאל של הכותרת ב-RTL. מופיע מעל התוכן ללא הזזת הרשימה, ללא חסימת לחיצות, ויכול להישבר לשורות ברוחב צר. אין רכיב משותף חדש או שינוי ב-Toast התחתון.
- נוסח הטקסט המועתק מוגדר בבריף בלבד. מחרוזות הממשק נשמרות ב-`messages/he.json` בעת המימוש.

## User Flow

1. לחיצה על אייקון ההעתקה לוכדת את הפריטים הלא מסומנים בסדר התצוגה.
2. אייקון טעינה מחליף זמנית את אייקון ההעתקה באותו שטח. אין נעילת הרשימה או השהיה מלאכותית.
3. לאחר הצלחה האייקון הרגיל חוזר, ובועית קטנה עם וי ו״הרשימה הועתקה״ מופיעה למשך 2.4 שניות.
4. המשתמש מדביק בכל יעד שיבחר. ההעתקה אינה משנה את הרשימה ואינה פותחת יישום אחר.

## States

| מצב | תצוגה והתנהגות |
|---|---|
| טעינת הרשימה או שגיאת טעינה | נשאר המסך הקיים; הפעולה זמינה רק לאחר טעינה |
| רגיל | אייקון העתקה בלבד, ללא משוב קבוע או שטח ריק שמור |
| העתקה | ספינר, `aria-busy`, שם נגיש ״מעתיק…״ וחסימת הפעלה נוספת |
| הצלחה | ״הרשימה הועתקה״ למשך 2.4 שניות; אפשר להעתיק שוב מיד |
| אין פריטים לקנייה | אייקון מעומעם, `aria-disabled`, והסבר ״אין פריטים לקנייה״. אין כתיבה ללוח |
| כשל העתקה | ״לא הצלחנו להעתיק. נסו שוב״ בצבע `danger`. האייקון חוזר לפעילות; השגיאה נעלמת בתחילת ניסיון נוסף או ביציאה |
| שינוי במהלך העתקה | הבקשה הפעילה מסיימת עם התוכן שנלכד. העתקה נוספת משתמשת במצב החדש |
| יציאה או מעבר לרשימה אחרת | המשוב והטיימרים מתנקים; אין הודעה מאוחרת מהמסך הקודם |

כשמספר הפריטים שנותרו מגיע לאפס במהלך בקשה, מציגים תחילה את תוצאת ההעתקה. לאחר משוב ההצלחה עוברים להסבר הריק; בכשל מציגים גם את הסבר הריק. האייקון נשאר חסום כל עוד אין פריטים להעתקה.

## RTL / Hebrew Notes

- טקסטים סופיים: ״העתק רשימה״, ״מעתיק…״, ״הרשימה הועתקה״, ״אין פריטים לקנייה״, ״לא הצלחנו להעתיק. נסו שוב״.
- הכותרת והמשוב RTL, עם ריווח לוגי. האייקונים אינם כיווניים; חץ החזרה הקיים נשאר ימינה.
- טקסט ההעתקה שומר על עברית, אנגלית ומספרים בדיוק כפי שהוזנו. אין הוספת כותרת, הוראות או מציין מקום לכמות חסרה.

### נגישות ותנועה

- כפתור מקורי עם `aria-label`, הפעלה ב-Enter וב-Space ופוקוס גלוי. התווית זמינה גם בפוקוס מקלדת.
- השבתה באמצעות `aria-disabled` וחסימת הפעולה משמרת פוקוס. אייקונים דקורטיביים מוסתרים מקורא המסך.
- הצלחה וריק מוכרזים באזור סטטוס, ושגיאה כ-alert, ללא הכרזה כפולה. הפוקוס אינו זז. הצלחות חוזרות מוכרזות גם כשהטקסט זהה.
- משוב הלחיצה הקיים נשמר; בועית המשוב מופיעה ונעלמת באטימות במשך 150 מילישניות. אין אנימציה על הפריטים. ב-reduced motion אין תנועה, והספינר סטטי.
- ניסיון חוזר מנקה את המשוב והטיימר הקודמים; הצלחה חוזרת מתחילה מחדש 2.4 שניות.

## Design System Impact

שימוש בבקרת האייקון הקיימת במקום הכפתור הרחב שנדחה. אין שינוי בצבעים, בגופנים, בפעולות הקנייה או בעיצוב סוגי הרשימות האחרים.

## Verification

המימוש נבדק בדפדפן עם נתוני דמה: העתקה והדבקה בפועל, שגיאות, מצב ריק, מקלדת, reduced motion, שם רשימה ארוך ו-RTL ברוחבי 1280, 640 ו-375 פיקסלים. תוצאות וצילומים ב-[tasks.md](tasks.md). המוקאפ המקורי נשאר הדמיה בלבד.
