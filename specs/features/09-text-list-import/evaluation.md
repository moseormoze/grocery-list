# בדיקת איכות פענוח עברית

ערכה של 12 קלטים כוללת את עשר דוגמאות הבריף, רשימה מרובת שורות וטקסט בפורמט כפתור ההעתקה. ההשוואה בודקת שם, כמות ושלילה לפי סדר. כמויות שקולות מתקבלות אם הוגדרו במפורש בערכה.

להרצה משורש ענף T1 עם Node 24 ומפתח Anthropic ב־.env.local:

```sh
node --env-file=.env.local scripts/evaluate-text-import.mjs
```

הדוח נשמר לצד קובץ זה עם תאריך הריצה. לכל דוגמה מוצלחת נרשמים הפלט שהתקבל, הזמן והטוקנים שדיווח השירות. במקרה של כשל בהתקשרות, הריצה שומרת את מה שהתקבל ועוצרת. ניסוי ראשון נעצר לפני קבלת תשובה עקב ENOTFOUND. כל 12 הדוגמאות ממתינות למדידת איכות.
