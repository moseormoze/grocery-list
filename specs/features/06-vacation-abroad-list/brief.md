# Feature: רשימת חופשה בחו״ל מוכנה מראש

## Problem

כשבני זוג מתכוננים לחופשה בחו״ל, רשימה ריקה מחייבת אותם לזכור ולנסח מחדש עשרות פריטי אריזה בסיסיים. הדבר מגדיל את הסיכוי לשכוח מסמך, תרופה או מטען, ומעביר את ניהול ההכנות בחזרה לוואטסאפ או ל-Notes. בנוסף, המסך הקיים משתמש בשפה ובפעולות של קניות — „הכול בעגלה” ו„סיימתי קניות” — שאינן מתאימות לצ׳קליסט אריזה ועלולות לגרום למחיקת פריטים שהמשתמש עדיין צריך לראות.

## User Story

As one of two partners preparing for an international vacation, I want to create a shared packing list that already contains common items, so that we can start checking and adapting it immediately instead of building it from scratch.

## Scope — What's In

- סוג רשימה מובנה חדש עם המפתח `vacation_abroad`, התווית „חופשה בחו״ל” ואייקון מזוודה.
- הסוג מופיע כאפשרות רביעית בזרימת יצירת הרשימה. שם הרשימה נשאר שדה חופשי ונדרש, כמו היום.
- יצירת הרשימה יוצרת פעם אחת גם את כל הפריטים ההתחלתיים. כל פריט נוצר לא מסומן, ללא כמות ובקטגוריה המוגדרת לו.
- פתיחת הרשימה הראשונה מציגה את התוכן שכבר נוצר. פתיחות נוספות אינן מוסיפות, משחזרות או משכפלות פריטים.
- כל ההתנהגויות הקיימות לפריט נשמרות: סימון וביטול סימון, הוספה, עריכה, מחיקה, שינוי קטגוריה, סידור ושיתוף עם השותף.
- פריט חדש שהמשתמש מוסיף מתחיל בקטגוריית „אחר”, וניתן לבחור לו קטגוריה אחרת בטופס.
- שפת ההתקדמות מותאמת לרשימת אריזה:
  - אין פריטים מסומנים: „מתחילים לארוז”.
  - חלק מהפריטים מסומנים: „האריזה בעיצומה”.
  - כל הפריטים מסומנים: „הכול ארוז”.
  - בכרטיס הרשימה, מצב השלמה מלאה מציג „הכול ארוז” במקום „הכול בעגלה”.
- ברשימת `vacation_abroad` לא מוצגים הכפתור והמודאל „סיימתי קניות”; סימון אינו מוחק או מאחסן פריטים.
- קטגוריות הרשימה, לפי הסדר:
  1. מסמכים וכסף
  2. אלקטרוניקה
  3. רחצה ובריאות
  4. ביגוד והנעלה
  5. ים ובריכה
  6. לטיסה ובדרך
  7. אחר
- התוכן ההתחלתי:
  - **מסמכים וכסף:** דרכונים; כרטיסי טיסה; אישורי הזמנות; ביטוח נסיעות; רישיונות נהיגה; רישיון נהיגה בינלאומי; כרטיסי אשראי; מזומן מקומי.
  - **אלקטרוניקה:** טלפונים; מטענים; אוזניות; סוללה ניידת; מתאם לשקע; מפצל; סים מקומי או eSIM.
  - **רחצה ובריאות:** מברשות שיניים; משחת שיניים; דאודורנט; כלי רחצה; תרופות אישיות; משככי כאבים; ערכת עזרה ראשונה; קרם הגנה; דוחה יתושים.
  - **ביגוד והנעלה:** חולצות; מכנסיים; בגדים לערב; לבנים; גרביים; בגדי שינה; בגדי ים; עליונית קלה; נעלי הליכה; סנדלים או כפכפים.
  - **ים ובריכה:** משקפי שמש; כובע; מגבות חוף; תיק חוף; נעלי מים; שקית אטומה למים.
  - **לטיסה ובדרך:** תיק יד; בקבוק מים; מגבונים; ג׳ל חיטוי; ספר; משחק קטן.
  - **אחר:** ללא פריטים התחלתיים.

## Out of Scope

- סוג רשימה „חופשה בארץ”.
- התאמת התוכן ליעד, עונה, מזג אוויר, משך החופשה, מספר נוסעים או אופי הטיול.
- בחירה בין כמה תבניות, שאלון הכנה או יצירת תוכן בעזרת AI.
- תוויות „חובה” או „אופציונלי”, הערות מפורטות, קישורים, תאריכי תפוגה או מסמכים מצורפים.
- כמויות התחלתיות או פריטים נפרדים לכל אחד מבני הזוג.
- שחזור התבנית, איפוס הרשימה או הוספת פריטי ברירת המחדל מחדש לאחר היצירה.
- שינוי זרימת „סיימתי קניות” בסוגי הרשימות הקיימים.
- שינוי מודל השיתוף, ההרשאות או הסנכרון הקיים.

## Acceptance Criteria

- [ ] במסך יצירת רשימה מוצגת אפשרות רביעית בשם „חופשה בחו״ל” עם אייקון מזוודה ומספר הקטגוריות הנכון: „7 קטגוריות”.
- [ ] בחירת „חופשה בחו״ל”, הזנת שם ולחיצה על „צור” יוצרות רשימה מסוג `vacation_abroad` המשותפת לאותו משק בית.
- [ ] בפתיחה הראשונה הרשימה מכילה בדיוק את 46 הפריטים המוגדרים ב-Scope, תחת שש הקטגוריות המתאימות; כל הפריטים אינם מסומנים וללא כמות.
- [ ] קטגוריית „אחר” קיימת בבורר הקטגוריות גם כשאין בה פריטים התחלתיים.
- [ ] רענון או פתיחה חוזרת של הרשימה אינם משנים את מספר הפריטים ואינם יוצרים כפילויות.
- [ ] מחיקת פריט התחלתי ולאחר מכן פתיחה חוזרת אינה מחזירה אותו.
- [ ] מחיקת כל הפריטים ולאחר מכן פתיחה חוזרת משאירה רשימה ריקה ומציגה את מצב הריק הקיים.
- [ ] שני שותפים באותו משק בית רואים את אותם פריטים ואת שינויי הסימון, העריכה והמחיקה דרך מנגנון הסנכרון הקיים.
- [ ] סימון פריט מציג אותו כמסומן אך אינו מסיר אותו מהרשימה.
- [ ] במצב 0 מתוך N מוצג „מתחילים לארוז”; במצב חלקי מוצג „האריזה בעיצומה”; ובמצב N מתוך N מוצג „הכול ארוז”.
- [ ] בכרטיס של רשימת חופשה שכל פריטיה מסומנים מוצג „הכול ארוז”, ולא מופיע הטקסט „הכול בעגלה”.
- [ ] הכפתור „סיימתי קניות” והמודאל שלו אינם מוצגים ברשימת חופשה, גם כשיש פריטים מסומנים.
- [ ] הוספת פריט חדש לרשימת חופשה מציעה את שבע הקטגוריות, עם „אחר” כברירת המחדל.
- [ ] שם הרשימה, שמות הפריטים והקטגוריות מוצגים ב-RTL תקין; הטקסט `eSIM` נשאר קריא בתוך השורה העברית.
- [ ] אם יצירת התוכן ההתחלתי נכשלת, המשתמש אינו נוחת על רשימת חופשה חלקית; מוצגת שגיאה בעברית וניתן לנסות שוב.
- [ ] שלושת סוגי הרשימות הקיימים ממשיכים להיווצר ריקים ולהציג את שפת הקניות הקיימת ללא שינוי.

## Dependencies

- **Depends on:** יצירה ותצוגה של רשימות ופריטים מ-`01-mvp`; מודל השיתוף והסנכרון הקיים; מקור הקטגוריות `SECTIONS_BY_TYPE`.
- **Blocks:** סוגי רשימות מוכנות נוספים, ובהם „חופשה בארץ”, יוכלו להשתמש באותו מנגנון תבנית בעתיד.
