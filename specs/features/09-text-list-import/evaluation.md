# בדיקת איכות פענוח עברית

ערכה של 12 קלטים כוללת את עשר דוגמאות הבריף, רשימה מרובת שורות וטקסט בפורמט כפתור ההעתקה. ההשוואה בודקת שם, כמות ושלילה לפי סדר. כמויות שקולות מתקבלות אם הוגדרו במפורש בערכה.

להרצה משורש ענף T1 עם Node 24 ומפתח Anthropic ב־.env.local:

```sh
node --env-file=.env.local scripts/evaluate-text-import.mjs
```

הדוח נשמר לצד קובץ זה עם תאריך הריצה. לכל דוגמה מוצלחת נרשמים הפלט שהתקבל, הזמן והטוקנים שדיווח השירות. במקרה של כשל בהתקשרות, הריצה שומרת את מה שהתקבל ועוצרת. ניסוי ראשון נעצר לפני קבלת תשובה עקב ENOTFOUND. בהרצה ממחשב המשתמש התקבלו [12 תשובות חיות](evaluation-2026-11-19T17-26-38-131Z.json). עשר התאימו במלואן. כל 18 השמות ודגלי השלילה תאמו, ו-16 מתוך 18 הכמויות תאמו לפורמט המבוקש. בשני המקרים האחרים המודל כתב את המספר במילים לפני היחידה. אחרי הוספת המרה לספרות למספר קטן עם יחידה מוכרת, בדיקה חוזרת של התשובות השמורות עברה בכל 12 הדוגמאות. ההנחיות והמודל נשארו זהים. התוצאה האחרונה נמדדה על ההקלטה של הריצה החיה.
