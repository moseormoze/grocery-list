# Feature: העתקת רשימה לשיתוף

סטטוס: הבריף והעיצוב המעודכנים אושרו ב-2026-11-16. ההגדרה הנוכחית מחליפה את רעיון הפרומפט בהעתקת רשימה בלבד, עם אייקון משני ליד ״ערוך״. הפירוק למשימות אושר; T1 ו-T2 מומשו; המיזוג עדיין ממתין לסקירת המשתמש. מקור: [Discovery](../../discovery/08-shopping-prompt-export.md).

## Problem

כשאחד מבני הזוג רוצה לשתף את רשימת הקניות בהודעה או להעביר אותה לכלי אחר, הוא צריך להעתיק ידנית פריטים וכמויות. נדרש טקסט שאפשר להדביק מיד בכל מקום; הוראות לקנייה באמצעות AI מפריעות לשיתוף כללי ומחייבות מחיקה שלהן לפני ההדבקה.

## User Story

כמשתמש ברשימה משותפת, אני רוצה להעתיק את הפריטים שנותרו לקנייה וכמויותיהם בלחיצה, כדי לשתף אותם במהירות.

## Scope — What's In

- פעולת ״העתק רשימה״ משנית ולא בולטת בכותרת, זמינה לשני השותפים באמצעות אייקון ליד ״ערוך״.
- ההיקף הקודם נשמר: רשימות סופר בלבד ורק פריטים שלא סומנו כנקנו. זרימת ההעתקה פועלת במחשב וגם במסך צר.
- טקסט פשוט: כל פריט בשורה, לפי סדר הופעתו ברשימה. אם קיימת כמות, הפורמט הוא `שם — כמות`; אחרת שם בלבד. השמות והכמויות נשמרים כפי שהוזנו.
- אין כותרת, שם רשימה, קטגוריות, תבליטים, הוראות, סיכום או טקסט חלופי לכמות חסרה.
- ההעתקה משקפת את הנתונים הזמינים באפליקציה בזמן הלחיצה ואינה משנה את הרשימה המשותפת. העתקה חוזרת משתמשת בנתונים הזמינים מחדש.
- הצלחה: ״הרשימה הועתקה״. אם אין פריטים להעתקה: ״אין פריטים לקנייה״, ללא כתיבה ללוח. כשל: ״לא הצלחנו להעתיק. נסו שוב״, עם אפשרות לניסיון נוסף.

דוגמת תוכן מועתק:

```text
חלב 3% — 2 קרטונים
עגבניות — 1 ק״ג
לחם
```

## Out of Scope

- פרומפט, AI, חיבור לכלי או לחנות, מילוי סל והזמנה.
- חלונית שיתוף, בחירת נמען, שליחת הודעה, קובץ, קישור או עורך תוכן לפני העתקה.
- סוגי רשימות נוספים, שילוב רשימות, פריטים שנקנו או בורר לפריטים להעתקה.
- שינוי מודל הנתונים, ההרשאות או הסנכרון, וסימון אוטומטי של פריטים כנקנו.

## Acceptance Criteria

- [ ] הפעולה זמינה ברשימת סופר בלבד, נגישה במחשב ואינה נחתכת במסך צר.
- [ ] ההדבקה כוללת כל פריט לא מסומן מהרשימה הנוכחית פעם אחת, בסדר התצוגה, ללא פריטים מסומנים או תוכן מרשימה אחרת.
- [ ] כמות קיימת נשמרת בדיוק לצד השם; פריט ללא כמות מופיע כשם בלבד. אין טקסט נוסף מעבר לשורות הפריטים.
- [ ] עברית, אנגלית, מספרים וכמויות חופשיות נשמרים בטקסט המועתק.
- [ ] ברשימה ריקה או כשכל הפריטים מסומנים, מוצג ״אין פריטים לקנייה״ ותוכן הלוח אינו נדרס.
- [ ] ״הרשימה הועתקה״ מופיע רק אחרי הצלחה. בכשל מוצגת שגיאה, מתאפשר ניסיון נוסף ומצב ההמתנה מסתיים.
- [ ] ההעתקה אינה משנה פריטים או מצבם אצל אף שותף. שינוי שהתקבל לפני העתקה חוזרת מופיע בטקסט החדש בלבד.

## Dependencies

- **Depends on:** תצוגת רשימה, שם/כמות/סימון וסדר הפריטים, זיהוי סוג הרשימה, הסנכרון הקיים ויכולת העתקה ללוח בדפדפן.
- **Blocks:** אין.

## Open Questions

אין שאלות מוצר חוסמות. סופר בלבד ופריטים שלא נקנו נשארו מההחלטות הקודמות; לא הורחבו בעקבות שינוי מטרת השיתוף.
